# 기본탄·캡슐·소형 폭발 — 다음 제작 묶음

기체 뱅킹 채택 다음 작업으로 디자인 연구 시트를 만들었다.
[연구 시트](candidates/combat-study-v1.png)는 **1536×1024 불투명 검토 그림**이며,
실제 PNG 스프라이트나 바로 잘라 쓸 수 있는 Atlas가 아니다. 확대된 픽셀 표현과
단계별 실루엣을 검토하는 자료다. 크롭·축소해 생산 에셋으로 대체하지 않는다.

기존 사용자 피드백과 전투의 의미를 유지한다. 아군탄은 황금색의 수평 바늘,
적탄은 자홍색 원형, 캡슐은 청록색 마름모다. 통합 스타일 시트의 청록 아군탄은
기존 아군/적 식별 개선을 되돌리므로 사용하지 않는다.

| 대상 | 현재 실제 원본 | 다음 원본 기준 |
| --- | --- | --- |
| 아군 기본탄 | 8×3, 황금/아이보리 | 오른쪽을 향한 가는 탄두와 짧은 꼬리. 1배에서 길이 방향을 읽을 수 있게 하고 불필요한 색 수를 늘리지 않는다 |
| 적 기본탄 | 6×6, 자홍/연분홍/짙은 자주 | 원형 실루엣과 밝은 중심. 캡슐 같은 뾰족한 마름모를 피한다 |
| 파워 캡슐 | 10×8, 청록/코발트 | 마름모 외곽, 작은 중심 반사. 적탄과 구분되는 폭/방향 유지 |
| 소형 폭발 | 48×48 × 9프레임 | 같은 중심/피벗, 하드 알파, 점화→팽창→파열→잔화→소멸. 기존 30fps/0.3초 유지 |

모두 기존 PPU16/피벗/표시 배율과 판정을 유지한다. 충돌 영역이나 발사 수치는
이 묶음에 포함하지 않는다. 일반/플래시 감소의 tint·불투명도 및 위험 표시가 폭발보다
앞에 오는 기존 정렬 규칙도 유지한다.

## 폭발 프레임 설계

연구 시트에는 8개 핵심 자세가 있으나 현재 게임은 9프레임을 `frames.Length / 30f`초
동안 재생한다. 그림 숫자만 맞춰 8장으로 바꾸면 0.267초로 짧아지므로, 아래처럼
**9개 native 원본**을 제작한다. 시트의 8장은 타이밍 계약이 아니다.

| 프레임 | 시점 | 목표 실루엣 |
| --- | --- | --- |
| 00 | 0ms | 작은 점화와 짧은 방사형 스파크 |
| 01 | 33ms | 날카로운 황백색 충격 별, 밝은 면적 제한 |
| 02 | 67ms | 조밀한 주황 팽창, 중심 위치 고정 |
| 03 | 100ms | 비대칭 불꽃 덩어리의 최대 팽창 |
| 04 | 133ms | 중심이 열리며 고리가 끊어지기 시작 |
| 05 | 167ms | 파열한 불꽃이 서로 떨어짐 |
| 06 | 200ms | 작고 어두운 붉은 잔화, 밝은 중심 소실 |
| 07 | 233ms | 드문 잔화와 적은 청회색 연기 |
| 08 | 267ms | 거의 사라진 몇 개의 점; 300ms에 풀 반환 |

원형 화염 덩어리를 그대로 반복하지 않는다. 정점 이후 면적과 밝기가 감소하며,
화면을 가리는 연기와 오래 남는 흰 원판을 만들지 않는다. 연구 시트 04의 밝은
덩어리는 native 크기와 전투 배경 위에서 면적을 줄일 필요가 있는 검토 대상이다.

## 원본 제작과 검수 순서

1. 작은 탄/캡슐은 위 실제 캔버스의 원본 후보로 비교한다. 현재 native API의 최소
   16×16 출력은 8×3/6×6/10×8 계약에 맞지 않는다. 큰 생성물을 축소해 native 완성으로
   보고하지 않고, 정확한 크기를 다룰 수 있는 제작 경로부터 확보한다.
2. 폭발은 48×48 투명 원본과 정확히 9개의 반환 프레임을 검수한다. 생성 결과 수와
   요청 수가 다르면 실제 반환을 기록하고 프레임 복제/재타이밍을 숨기지 않는다.
3. 1배/2배/정수 확대와 테마 0·2·4의 실제 전투 표시 배율로 확인한다. 동시 표시한
   아군탄/적탄/캡슐이 색과 형태 모두로 읽히는지, 폭발이 위험을 가리는지 확인한다.
4. 원본 크기·피벗·알파·팔레트·중심 이동과 9프레임의 소멸 흐름을 감사한다.
   사람에게 비교/루프를 제시해 채택 후 씬/빌더/Atlas 연결과 회귀/웹 빌드를 진행한다.

현재 완료: 기존 자산/재생 계약 조사, 연구 시트, 원본·프레임 제작 기준.
남음: native 원본 제작, 전체 폭발 루프, 사람 큐레이션, 게임 적용.

추가 과금을 하지 않았다. 기존 파일럿 사용량 기록은 변경하지 않았다.
